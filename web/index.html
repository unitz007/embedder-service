✨ REST API

Code Indexer Service

Semantic search infrastructure for codebases. Index any GitHub repository or local project, generate embeddings with CodeBERT or Voyage AI, and query with natural language.

pgvector storage
Voyage AI (cloud, large repos)
CodeBERT (local, small repos)
BASE URL http://localhost:8080
Endpoints
Indexing
POST /github/index Index a GitHub repo or local path ▼

Queues an indexing job. Accepts a GitHub owner/repo (public repos need no token) or an absolute server-side path. Automatically selects Voyage AI for repos > 500 chunks, CodeBERT otherwise. 🔓 no auth required

Request body

FieldTypeDescription
ownerstringoptGitHub owner/org
repostringoptGitHub repo name
refstringoptBranch, tag, or commit SHA
pathstringoptAbsolute local directory path (alternative to owner/repo)
namespacestringoptStorage namespace (defaults to owner)
project_idstringoptProject identifier (defaults to repo)
access_tokenstringoptGitHub OAuth token — required for private repos
webhook_urlstringoptURL to POST job status updates to

Example — public GitHub repo

{
  "owner": "vercel",
  "repo":  "next.js"
}

Example — local path

{
  "path":       "/opt/repos/my-service",
  "namespace":  "acme",
  "project_id": "my-service"
}

Response

{
  "status":     "queued",
  "job_id":     "a3f9c1...",
  "namespace":  "vercel",
  "project_id": "next.js"
}
POST /embeddings/{namespace}/{project_id} Upload a zip and index it ▼

Accepts a multipart/form-data upload of a zipped repository. 🔒 Bearer token required

Form fields

FieldTypeDescription
code_zipfilereqZip archive of the repository
webhook_urlstringoptURL to POST job status updates to

Example (curl)

curl -X POST \
  -H "Authorization: Bearer <token>" \
  -F "code_zip=@repo.zip" \
  /embeddings/acme/my-service

Response

{
  "status":     "queued",
  "job_id":     "b2e4d8...",
  "namespace":  "acme",
  "project_id": "my-service"
}
Search
POST /search/text Search with raw query — recommended ▼

The simplest search endpoint. Pass a plain-text query; the server reads the index metadata and automatically picks the correct embedding model (Voyage AI or CodeBERT). No pre-computed embedding needed. 🔓 no auth required

Request body

FieldTypeDescription
namespacestringreqNamespace of the indexed project
project_idstringreqProject identifier
querystringreqNatural language search query
kintegeroptNumber of results (default: 5)

Request

{
  "namespace":  "vercel",
  "project_id": "next.js",
  "query":      "how does file-system routing work",
  "k":          5
}

Response

{
  "namespace":  "vercel",
  "project_id": "next.js",
  "embedder":   "VoyageEmbedder",
  "results": [
    {
      "rank":             1,
      "similarity_score": 0.91,
      "metadata": {
        "file_path":   "packages/next/src/server/...",
        "chunk_type":  "function",
        "symbol_name": "resolveFilesystemRoute",
        "content":     "..."
      }
    }
  ]
}
POST /search Search with a pre-computed embedding ▼

Search using a vector you already computed. Optionally include the raw text field so the server can re-embed automatically on dimension mismatch. 🔓 no auth required

Request body

FieldTypeDescription
namespacestringreqNamespace of the indexed project
project_idstringreqProject identifier
embeddingfloat[]reqQuery vector
kintegeroptNumber of results (default: 5)
textstringoptRaw query text — used for auto re-embedding on dimension mismatch

Request

{
  "namespace":  "vercel",
  "project_id": "next.js",
  "embedding":  [0.021, -0.134, ...],
  "k":          5
}
POST /embed Embed a text string ▼

Embed arbitrary text. Provide namespace + project_id and the server auto-selects the correct model from index metadata. 🔓 no auth required

Request body

FieldTypeDescription
textstringreqText to embed
namespacestringoptUsed to auto-detect the right model
project_idstringoptUsed to auto-detect the right model
use_cloudbooleanoptForce Voyage AI (default: false)

Request

{
  "text":       "how does routing work",
  "namespace":  "vercel",
  "project_id": "next.js"
}

Response

{
  "embedding": [0.021, -0.134, ...],
  "model":     "voyage-code-3"
}
Management
GET /jobs/{job_id} Poll indexing job status ▼

Returns the current status of an indexing job. Status values: queued → downloading → running → completed | failed 🔒 Bearer token required

Path params

ParamTypeDescription
job_idstringreqJob ID returned by an index endpoint

Response

{
  "job_id":        "a3f9c1...",
  "status":        "completed",
  "namespace":     "vercel",
  "project_id":    "next.js",
  "total_vectors": 2841,
  "embedder":      "VoyageEmbedder",
  "created_at":    "2024-01-15T10:32:00Z",
  "updated_at":    "2024-01-15T10:34:18Z"
}
GET /embeddings/{namespace}/{project_id} Get index info ▼

Returns metadata about a stored index: vector count, embedder, model, dimension. 🔒 Bearer token required

Path params

ParamTypeDescription
namespacestringreqStorage namespace
project_idstringreqProject identifier

Response

{
  "namespace":     "vercel",
  "project_id":    "next.js",
  "total_vectors": 2841,
  "embedder":      "VoyageEmbedder",
  "model":         "voyage-code-3",

  "use_cloud":     true
